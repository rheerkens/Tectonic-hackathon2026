# Agent activity clips

## Register

product

## Users

SD Trust payroll consultants waiting for an answer while the agent reviews organisational sources. The repository README defines the portfolio handover workflow and the need to inspect trustworthy, current information.

## Product Purpose

Short, reusable visual loops illustrate the sources the agent reads. The earlier video thread requests Teams, Outlook and SharePoint, with PDF reading, expert discovery and access checking as supporting scenes. An offline HTML gallery lets the team review the exported clips together.

## Brand Personality

Familiar, precise, calm. Preserve the actual source application's published interface. Captions are Dutch, matching the existing clips. These are illustrative progress animations, not evidence of live integrations.

## Anti-references

The user explicitly rejects invented Microsoft interface layouts. Do not redraw Microsoft chrome, substitute letter badges for logos, or generate synthetic screenshot text. Use the original public product screenshots and retain a source manifest.

## Design Principles

1. Keep original screenshot pixels intact; motion belongs in a separate agent overlay.
2. Highlight real visible content, without inventing messages or results.
3. Make loops unobtrusive and seamless, with a clean interval between passes.
4. Keep the full interface recognisable and offer full-screen video review.

## Accessibility & Inclusion

Preserve the existing reduced-motion support, give previews a pause control, and provide descriptive labels. Videos are silent and have native controls.
